# 未语 UI 设计系统

## 设计原则

- 让信、情绪和小刺猬承担叙事，界面本身保持安静。
- 用留白、排版和表面色差建立层级，不依赖厚重阴影或装饰。
- 每个页面只保留一个视觉主动作；次要动作退为浅色表面。
- 动效只回应进入、选择与确认，主要使用轻微位移、缩放和透明度。

## 色彩

- 页面背景：`#F7F3EE`
- 主表面：`#FFFDFC`
- 暖色卡片：`#FBF7F1`
- 主文字：`#332C27`
- 次级文字：`#746A61`
- 辅助文字：`#948A80`
- 雾蓝强调：`#6F919C`
- 深雾蓝：`#527A86`
- 浅雾蓝表面：`#E7F0F1`
- 边界：`#E8E0D7`
- 危险操作：`#9B6664`

## 排版

- 品牌标题：30fp / Medium
- 页面标题：24fp / Medium
- 区块标题：20–22fp / Medium
- 卡片标题：16–19fp / Medium
- 正文：15–16fp / Regular，行高 1.5–1.7
- 辅助文字：12–13fp / Regular

## 间距与圆角

- 基础节奏：4vp / 8vp
- 页面左右边距：20vp
- 模块间距：16–24vp
- 控件圆角：18vp
- 内容卡片：24vp
- 主叙事卡片：30vp
- 最小触控区域：48vp

## 层次与动效

- 普通卡片使用 1vp 柔和边界，无阴影或极轻阴影。
- 首页主卡允许轻微投影，其他页面不重复制造悬浮感。
- 点击与选择反馈控制在 160–260ms；星光类情绪反馈可延长至约 520ms 回落。
- 不使用循环装饰动画，不让动画阻塞输入。
